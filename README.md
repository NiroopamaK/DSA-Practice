# DSA Practice Repository

This repository contains a collection of **Data Structures and Algorithms (DSA) practice problems**, along with sample coding questions inspired from platforms like **HackerRank** and **LeetCode**.

The goal of this repository is to strengthen problem-solving skills by practicing common interview patterns and core DSA concepts.

---

## Sources of Problems

Problems are inspired from:
- LeetCode
- HackerRank
- General DSA interview questions

---

## Approach

Most problems in this repository include:
- Brute force approach (when applicable)
- Optimized solution
- Time and space complexity analysis
- Clean and readable Python implementations
